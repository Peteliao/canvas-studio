# Canvas Studio

> 零依赖 · 完全离线 · 开箱即用的单页画布编辑器

Canvas Studio 是一个运行在浏览器里的画布编辑器：无需构建、无需安装、无需联网，所有数据只保存在本机。打开 `index.html` 即可开始设计。

**在线使用：<https://peteliao.github.io/canvas-studio/>** —— 打开即用，无需下载安装。

## 快速开始

**在线版（推荐）**

直接打开 <https://peteliao.github.io/canvas-studio/>。

**本地运行**

双击 `index.html`（推荐使用最新版 Chrome / Edge），或启动本地服务器：

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

没有依赖、没有构建步骤，整个应用只有三个文件。

> 在线版与本地版的数据相互独立：画布存档保存在各自地址（origin）的浏览器本地存储中，互不影响。

## 功能总览

### 绘制与编辑

- **图形库**：矩形、圆形、三角形、五角星、箭头、线条、贝塞尔曲线（拖动控制点调整弧度）
- **线条样式**：实线 / 虚线 / 点线 / 波浪线，波浪线可叠加虚线、点线描边
- **文本**：点击或拖框创建，富文本编辑，自动尺寸与换行，排版设置，导出保留换行
- **图片**：插入本地图片，素材库复用，蒙版裁剪
- **填充**：纯色 / 线性 / 径向 / 锥形渐变（角度与中心位置可调），不透明度，混合模式
- **描边与效果**：虚线描边、圆角、阴影
- **变换**：拖动移动、八向缩放、旋转（实时度数显示）、可拖拽旋转枢轴、方向键微调（步长可设，Shift ×10）

### 精准定位：四色可编辑标注

选中物件后自动显示四周标注，**所有数值都可以点击直接修改**（Enter 确认、Esc 取消、↑↓ 微调）：

| 颜色 | 含义 | 说明 |
| --- | --- | --- |
| 蓝色 | 边距 | 物件到画布边缘的距离 |
| 玫红 | 间距 | 与四向最近邻物件的带符号距离，负值 = 重叠深度 |
| 青色 | 辅助线距离 | 物件与辅助线的双向测距 |
| 橙色 | 边缘对齐差 | 与最近邻物件四条边的差值，0 = 已对齐，负 = 偏上 / 偏左 |

把橙色对齐差改成 0，对应边即刻精确对齐；把间距改成负值，即可精确控制重叠量。横向、纵向最近邻自动选取，斜对角物件也参与计算。

### 标尺与辅助线

- 从标尺拖出水平 / 垂直辅助线
- 辅助线可按任意角度旋转（双击或浮控输入度数）
- 拖回标尺或按 Delete 删除
- 虚线显示 + 对比色光晕，与物件同色时依然清晰可见
- 选中物件或辅助线时显示双向距离，数值可编辑，物件与辅助线互相调整

### 图层与素材

- 图层列表：搜索、重命名、排序（置顶 / 置底 / 上移 / 下移）、锁定、显示 / 隐藏、导出可见性
- 组合：Ctrl+G 编组、Ctrl+Shift+G 解组，组可折叠
- 六向对齐与分布，基准可切换「相对选区 / 相对画布」
- 素材库：图片存入 IndexedDB，跨项目复用

### 项目与版本

- 多项目管理：新建 / 切换 / 重命名 / 删除
- 版本快照：随时保存当前状态，可恢复、可删除
- 自动保存：编辑即写入本地存储，刷新自动恢复
- 项目文件：Ctrl+S 导出 JSON，可载入迁移与备份

### 导出

- 格式：PNG（无损 / 透明）/ JPEG / WebP / SVG（矢量）/ PDF（单页）
- 范围：整个画布 / 仅选中元素 / 按图层批量导出
- 自定义宽度（16–16000 px）、JPEG / WebP 质量、透明背景
- 浏览器不支持 WebP 时自动回退 PNG

### 界面

- 右侧检查器：属性 / 图层 / 素材 / 项目四个纵向标签，点击收起 / 展开，收起后仅留 42px 竖栏，状态持久记忆
- 浅色 / 深色主题，高对比度模式
- 网格（Ctrl+'）、智能吸附（对齐参考线）、标尺开关
- 缩放 10%–800%，Alt+Z 适应屏幕，触控双指缩放
- 响应式布局：窄屏下检查器自动切换为悬浮模式
- 尊重系统「减少动态效果」设置

## 数据与隐私

所有数据仅保存在本地浏览器，应用不发起任何网络请求（内置自检可验证）：

| 位置 | 内容 |
| --- | --- |
| localStorage `canvas_autosave_v2` | 当前项目自动存档 |
| localStorage `canvas_studio_settings_v3` | 界面与工具设置 |
| IndexedDB `CanvasAssetsDB` | 素材库、项目列表、版本快照 |

清空浏览器数据会删除本地项目，重要设计请用「保存项目」导出 JSON 备份。

## 项目结构

```
├── index.html   # 页面结构、SVG 图标与全部对话框
├── script.js    # 全部逻辑（IIFE 封装：模型 → 渲染 → 历史 → 自动存档）
├── style.css    # 浅色 / 深色主题与全部样式
├── README.md
├── .nojekyll    # GitHub Pages 直接托管静态文件
└── .gitignore
```

- 数据格式 schema v3，带校验与旧版本检测
- 无框架、无构建、无外部资源，修改任意文件后刷新即生效

## 内置自检

右侧「项目」面板 → 诊断 → 运行内置自检，覆盖数据模型、渲染、序列化、导出链路、本地存储、标注编辑、辅助线测距等 **22 项检查**。

## 浏览器支持

推荐使用最新版 Chrome / Edge，需要支持 localStorage、IndexedDB 与 Canvas 2D。触控设备支持双指缩放。
