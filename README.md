# Canvas Studio

> 离线可用 · 本地存储 · 开箱即用的单页画布编辑器

Canvas Studio 是一个运行在浏览器里的画布编辑器：无需联网，所有数据只保存在本机。在线版打开即用；源码使用 TypeScript（严格模式）编写，按模块组织，由 Vite 构建。

**在线使用：<https://peteliao.github.io/canvas-studio/>** —— 打开即用，无需下载安装。

## 快速开始

**在线版（推荐）**

直接打开 <https://peteliao.github.io/canvas-studio/>。

**本地开发**

需要 Node.js 18+：

```bash
npm install     # 安装依赖（TypeScript、Vite、内置字体包与 PSD 解码库 ag-psd）
npm run dev     # 启动开发服务器，默认 http://localhost:5173，支持热更新
```

**构建与预览**

```bash
npm run build     # 严格类型检查 + 生产构建，输出到 dist/
npm run preview   # 本地预览构建产物
npm run typecheck # 仅运行 TypeScript 严格类型检查
```

> 在线版与本地版的数据相互独立：画布存档保存在各自地址（origin）的浏览器本地存储中，互不影响。

## 功能总览

### 绘制与编辑

- **图形库**：矩形、圆形、三角形、五角星、箭头、线条，以及六边形、五边形、菱形、梯形、平行四边形、十字、半圆、心形、云朵、月牙、对话气泡、水滴 12 种矢量形状；贝塞尔路径统一用钢笔工具绘制
- **形状参数**：16 种菜单形状都可在右侧检查器「形状参数」卡片中调整特征数值，滑块与数值输入均可，实时改变轮廓并与导出保持一致：矩形圆角、圆形扇形角度 / 起始角度、三角形顶点位置、星形角数 / 内径、六边形与五边形边数、菱形腰线、梯形顶边宽度、平行四边形倾斜度、十字臂宽、半圆拱高、心形凹口、云朵蓬松度、月牙厚度、对话气泡尾巴位置 / 长度、水滴上尖长度
- **分组工具菜单**：左侧工具架把基础形状收进「形状」按钮、把箭头 / 线条 / 钢笔收进「线条」按钮，点击弹出二级菜单选择，图标会记住最近使用的工具（Photoshop 式）
- **透明特效**：左侧「特效」按钮内置 8 个透明装饰图案——水珠、流体、波浪、水花、气泡、柔光、彩带、极光；插入即带渐变高光与透明度，适合海报叠层装饰。选中后点色板或「填充」卡片即可一键换色，自动重算高光 / 暗部并保留透明度；流体 / 波浪 / 水花还可调整波瓣数、起伏、波幅、带宽、尖角数等轮廓参数
- **线条样式**：实线 / 虚线 / 点线 / 波浪线，波浪线可叠加虚线、点线描边
- **文本**：点击或拖框创建，富文本编辑，自动尺寸与换行，排版设置；内置开源思源黑体 / 思源宋体（随构建打包，完全离线可用），导出保留换行
- **图片与 PSD**：插入 PNG / JPEG / WebP / GIF / SVG 等本地图片，素材库复用，蒙版裁剪；支持直接导入 PSD / PSB，读取 Photoshop 保存的**拼合合成图**并转为普通图片图层（图层合并、不可再编辑单个图层），大图自动缩放到最长边 4096px
- **填充**：纯色 / 线性 / 径向 / 锥形渐变（角度与中心位置可调），渐变条支持最多 8 个色标——单击添加、拖动排序、逐个改色与位置，不透明度、混合模式；闭合的钢笔路径同样可填充
- **描边与效果**：描边可选纯色或线性 / 径向 / 锥形渐变（独立色标与角度 / 中心），虚线描边、圆角、阴影
- **变换**：拖动移动、八向缩放、旋转（实时度数显示）、可拖拽旋转枢轴、方向键微调（步长可设，Shift ×10）

### 曲线工具（钢笔 + 节点编辑）

曲线统一由钢笔工具绘制（没有独立的「插入曲线」按钮），画完即可用节点与控制柄自由整形，贝塞尔路径支持任意节点数、开放 / 闭合：

- **钢笔工具（P）**：单击加角点，按住拖拽即拉出圆滑曲线（自动对称控制柄），`Shift` 15° 吸附，`Alt` 拖拽断开对称；4px 拖动死区保证「单击」不会因手抖意外带出控制柄
- **曲线后接直线**：拖出控制柄后，`Alt` + 点击刚放下的锚点可收起它的出手柄；或落下新点时按住 `Alt`，自动收起上一个节点的出手柄，新生成的这一段即为直线（已画好的上一段形状不变）
- 点回起点闭合路径；`Enter` / 双击结束；`Esc` 放弃；`Backspace` 退回上一个节点
- 绘制过程实时预览路径、节点、控制柄与到指针的橡皮筋
- 路径的选中框 / 对齐基准使用**真实曲线边界**（按贝塞尔极值计算），不包括控制柄外扩区域，因此钢笔图形与画布或其它物件对齐后不会留下额外间隙
- 钢笔落点可吸附到邻近物件的端点、中点、圆心、象限点、黄金分割点、路径节点与画布关键点；落第一点前悬停即预览捕捉标记，笔尖保持十字光标，不会被物件上的移动手势挡住；按住 `Alt` 临时跳过捕捉
- **填充与描边分别可调**：在检查器「填充」卡片勾选「填充闭合路径」，可设置纯色 / 线性 / 径向 / 锥形渐变（渐变色标编辑器同样支持多色）、颜色与透明度；同一卡片下方可开关「显示描边」并单独设置描边颜色；粗细与实线 / 虚线 / 点线在下方「曲线样式」面板。开放路径始终只显示描边。旧存档默认不填充、保留描边，既有画面不受影响
- **节点编辑**：拖拽方块移动节点（控制柄跟随），拖拽圆形控制柄调弧度，`Alt` 断开对称
- 双击线段插入节点（De Casteljau 分割，**形状完全不变**）；双击节点删除
- `Ctrl+点击` 节点切换平滑 / 尖角
- 检查器「节点编辑」面板：插入 / 删除节点、平滑 / 尖角、闭合 / 断开、反转方向、适配边框
- 路径数据结构兼容 v3 单段曲线存档，旧项目打开后可直接继续编辑

### 颜料桶（矢量填色）

按 `B` 或点左侧「填色」使用。「填色」下方有**两个色块**：上为填充色、下为描边色。点击任一色块会弹出设置面板：预设色板与原生取色器可直接选色，拖动颜色即**实时预览、实时生效**，无需确认；十六进制色值输入同样边输入边生效（凑满 6 位立即应用）。选中物件时，面板中的**「无填充 / 无描边」**会立即去掉该物件的对应样式；**描边面板**还提供粗细滑块与数值输入（0–30px，线条 / 曲线最小 1px），与右侧属性面板双向同步。未选中物件时，面板只修改当前颜料桶色槽（也可设为「无」），之后颜料桶不再涂该类颜色。当前色块会高亮，在右侧「素材」标签页「颜色」面板点色板也会写入这个色槽；`Alt` + 点击画布元素可吸取对应区域的颜色。

- **交互识别填充 / 描边**：点击元素**内部**用填充色改填充，点击**边缘或描边线**用描边色改描边；按住 `Shift` 强制改描边；线条与开放曲线没有填充，一律改描边
- **悬停预览**：鼠标移到物件上即按识别结果高亮——填充目标在内部叠加半透明当前色，描边目标加亮轮廓；光标旁同时显示「填充 / 描边 · 色值」提示，点击前即可预知会改哪一处
- 点击元素即上色，按住拖动可连续为多个元素上色；`V` 返回选择工具
- 普通形状写入通用描边（自动启用），曲线写入 `line` 描边，文本写入文字色
- 这是**矢量填色**而非像素漫水：结果仍是结构化数据，PNG / SVG / PDF 导出与编辑器保持一致，缩放不失真
- 颜料桶模式下选色只改变对应色槽，不会顺带改动已选中元素或画布背景；切回其他工具后色板恢复「应用到选中元素」的原有行为

### 精准定位：可编辑尺寸标注

选中物件后自动显示尺寸线与距离标注，**所有数值都可以点击直接修改**（Enter 确认、Esc 取消、↑↓ 微调，Shift ×10）：

| 颜色 | 含义 | 说明 |
| --- | --- | --- |
| 蓝色实线 | 自身尺寸 | `W` / `H` 尺寸线贴着物件自身边缘，旋转后随边缘倾斜；`∠` 徽标显示旋转角度 |
| 蓝色虚框 | 画布边距 | 到画布四边的距离，近距离显示完整尺寸线，远距离收成短引线 |
| 玫红 | 间距 | 与四向最近邻物件的带符号距离，负值 = 重叠深度（箭头指示方向） |
| 青色 | 辅助线距离 | 物件与辅助线的双向测距 |
| 橙色 | 边缘对齐差 | 每个方向只显示差值更小的一条边，0 = 已对齐（显示绿色 `✓ 对齐` 徽标） |

把橙色对齐差改成 0，对应边即刻精确对齐；把间距改成负值，即可精确控制重叠量。横向、纵向最近邻自动选取，斜对角物件也参与计算。标签自动避让、自动夹在视口内，不会跑出屏幕或叠在一起。

五类标注各自独立开关：底部状态栏左侧有「尺寸 / 边距 / 间距 / 对齐 / 辅助线」五个色点按钮，点击或按快捷键 `1`–`5`（数字键盘、全角数字与中文输入法状态均可）即可单独隐藏某类数值，只留需要的信息；焦点在数值输入框时数字键仍用于输入，改用 `Alt+1`–`Alt+5` 同样可切换。顶部工具条的标注总开关仍可一键隐藏全部标注。

### 智能捕捉

状态栏的「捕捉」按钮与快捷键 `6` / `Alt+6` 控制全部捕捉开关（与顶部磁铁按钮同步），也可在菜单「视图 → 智能捕捉」切换：

- **捕捉点**：物件四角 / 端点、边中点、几何中心、圆心、圆与椭圆的四象限点、各边与内部的黄金分割点、曲线路径节点；画布四角、中心与黄金分割交点
- **移动与绘制**：拖动元素与钢笔落点均可吸附；捕捉点优先于边缘对齐参考线
- **角点锚定移动**：选中物件后按住 `Ctrl` / `⌘` 拖动任意缩放手柄，不再缩放，而是以该角点（或边中点）为锚点移动物件，锚点可直接吸附到其它物件的圆心、端点、黄金分割点等特征点；普通拖动手柄仍为缩放
- **视觉反馈**：命中时显示带类型标签的捕捉标记，锚定移动时同时显示青绿色锚点；边缘 / 中心对齐仍显示参考线
- `Alt` 临时绕过捕捉，按住绘图或拖动即可自由定位

### 标尺与辅助线

- 从标尺拖出水平 / 垂直辅助线
- 辅助线可按任意角度旋转（双击或浮控输入度数）
- 拖回标尺或按 Delete 删除
- 虚线显示 + 对比色光晕，与物件同色时依然清晰可见
- 选中物件或辅助线时显示双向距离，数值可编辑，物件与辅助线互相调整

### 图层与素材

- 图层列表：搜索、重命名、排序（置顶 / 置底 / 上移 / 下移）、锁定、显示 / 隐藏、导出可见性
- 组合：Ctrl+G 编组、Ctrl+Shift+G 解组，组可折叠
- 六向对齐与分布，基准可切换「相对选区 / 相对画布」
- 素材库：图片存入 IndexedDB，跨项目复用

### 项目与版本

- 多项目管理：新建 / 切换 / 重命名 / 删除
- 版本快照：随时保存当前状态，可恢复、可删除
- 自动保存：编辑即写入本地存储，刷新自动恢复
- 项目文件：Ctrl+S 导出 JSON，可载入迁移与备份

### 导出

- 格式：PNG（无损 / 透明）/ JPEG / WebP / SVG（矢量）/ PDF（单页）
- 范围：整个画布 / 仅选中元素 / 按图层批量导出
- 自定义宽度（16–16000 px）、JPEG / WebP 质量、透明背景；填充不透明度与渐变在 PNG / SVG 导出中与画布一致
- 浏览器不支持 WebP 时自动回退 PNG

### 界面

- 右侧检查器：属性 / 图层 / 素材 / 项目四个纵向标签，点击收起 / 展开，收起后仅留 42px 竖栏，状态持久记忆
- 浅色 / 深色主题，高对比度模式
- 网格（Ctrl+'）、智能捕捉（边缘参考线 + 端点 / 中心 / 黄金分割等捕捉点）、标尺开关
- 缩放 10%–800%，Alt+Z 适应屏幕，触控双指缩放
- 响应式布局：窄屏下检查器自动切换为悬浮模式
- 尊重系统「减少动态效果」设置

## 数据与隐私

所有数据仅保存在本地浏览器，应用不发起任何网络请求（内置自检可验证）：

| 位置 | 内容 |
| --- | --- |
| localStorage `canvas_autosave_v2` | 当前项目自动存档 |
| localStorage `canvas_studio_settings_v3` | 界面与工具设置 |
| IndexedDB `CanvasAssetsDB` | 素材库、项目列表、版本快照 |

清空浏览器数据会删除本地项目，重要设计请用「保存项目」导出 JSON 备份。

## 项目结构

```
├── index.html        # 页面结构、SVG 图标与全部对话框（入口挂载 /src/main.ts）
├── style.css         # 浅色 / 深色主题与全部样式
├── src/              # TypeScript 源码（严格模式，零 any）
│   ├── main.ts       # 启动入口
│   ├── types.ts      # 全部数据模型与交互状态类型
│   ├── constants.ts  # 常量、预设与快捷键表
│   ├── state.ts      # 全局状态与 DOM 节点缓存
│   ├── model.ts      # 数据校验、旧版迁移、元素工厂
│   ├── db.ts         # localStorage 设置与 IndexedDB 素材/项目/版本
│   ├── history.ts    # 撤销 / 重做 / 自动保存
│   ├── render.ts     # DOM 渲染与文本排版
│   ├── shapes.ts     # 16 种形状的参数规格与动态点位
│   ├── shapepanel.ts # 检查器「形状参数」卡片
│   ├── interaction.ts# 指针交互：拖拽 / 缩放 / 旋转 / 钢笔 / 节点
│   ├── snappoints.ts # 捕捉点生成与最近点吸附
│   ├── imageimport.ts# 图片解码与 PSD / PSB 合成图导入
│   ├── exporter.ts   # PNG / JPEG / WebP / PDF 画布导出
│   ├── vector-export.ts # SVG 矢量导出与 PDF 封装
│   ├── rail.ts       # 左侧工具架分组与二级弹出菜单
│   └── ...           # 面板、图层、样式、标注、裁剪、项目等模块
├── favicon.svg       # 品牌标徽（矢量主图，现代浏览器优先使用）
├── favicon.ico / favicon-16.png / favicon-32.png  # 标徽位图回退
├── apple-touch-icon.png  # iOS 主屏图标（180×180）
├── package.json / tsconfig.json / vite.config.ts  # 开发工具链配置
├── .github/workflows/deploy.yml  # 推送 main 自动构建并发布 GitHub Pages
├── README.md
└── .gitignore
```

- 数据格式 schema v4（兼容 v2 / v3 存档），带校验与旧版本自动迁移
- 无框架、无外部资源（内置思源字体随构建输出）；运行时仅 `ag-psd` 一个 PSD 解码库，且仅在导入 PSD 时按需加载，不增加首屏体积；TypeScript 完全严格模式，Vite 开发热更新、构建产物为纯静态文件

## 部署

推送到 `main` 分支后，GitHub Actions 自动执行类型检查与构建，并把 `dist/` 发布到 GitHub Pages（仓库 Settings → Pages 的 Source 需设为 **GitHub Actions**）。

## 内置自检

右侧「项目」面板 → 诊断 → 运行内置自检，覆盖数据模型、渲染、序列化、导出链路、多色标渐变填充与渐变描边、闭合曲线填充、曲线真实边界、捕捉点生成与吸附、矢量形状库、透明特效图案库、16 种形状参数、本地存储、标注编辑、辅助线测距等 32 项检查。

## 浏览器支持

推荐使用最新版 Chrome / Edge，需要支持 localStorage、IndexedDB 与 Canvas 2D。触控设备支持双指缩放。
